# calc Test Cases
# Format: Input -> Expected Output
#
# Input is the keys pressed, left to right. Expected is what the reading
# line shows afterwards. TAB switches entry mode; cases marked [expr] are
# in expression mode, everything else is immediate mode.
# Results carry 10 significant digits with trailing zeros trimmed.
# Sections 1 to 15 are the device. Section 16 is the console mode, where
# input is a whole line typed at a prompt and output is a printed line.

## 1. Basic Operations
1.1 Basic Addition
Input: 5 + 3 =
Expected: 8

1.2 Basic Subtraction
Input: 10 - 4 =
Expected: 6

1.3 Basic Multiplication
Input: 6 * 7 =
Expected: 42

1.4 Basic Division
Input: 15 / 3 =
Expected: 5

1.5 Power
Input: 2 ^ 10 =
Expected: 1024

## 2. Decimal Numbers
2.1 Decimal Addition
Input: 3.14 + 2.86 =
Expected: 6

2.2 Decimal Subtraction
Input: 5.5 - 2.2 =
Expected: 3.3

2.3 Binary Rounding Absorbed
Input: 0.1 + 0.2 =
Expected: 0.3

2.4 Trailing Zeros Trimmed
Input: 2.50 + 0.50 =
Expected: 3

2.5 Leading Decimal
Input: .5 + 2 =
Expected: 2.5

2.6 Trailing Decimal
Input: 5. + 2 =
Expected: 7

2.7 Leading Zeros
Input: 00005 + 3 =
Expected: 8

## 3. Negative Numbers

3.2 Both Operands Negative

## 4. Chaining (immediate mode)
